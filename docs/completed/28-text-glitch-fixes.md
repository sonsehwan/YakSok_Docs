# 28. 포트폴리오 촬영 중 발견한 문구 오류 2건

## 문제

실기기 촬영 중 화면 문구 두 곳이 틀린 것을 발견했다. 둘 다 동작 버그는 아니고 문자열 조합 실수다.

1. **공유자에게 가는 복약 완료 푸시 본문의 짝 없는 `'`** — `NotificationStatusChangedListener`가
   본문을 `약속명 + "의 " + MM-dd + " " + 시간대 + "' 복약을 완료했어요."`로 조립한다. 여는 따옴표는
   없고 닫는 따옴표만 있어 "비타민의 10-06 아침' 복약을…"처럼 나간다.
2. **홈 진행률 문구의 숫자 뒤바뀜** — `HomeFragment.updateProgress`가 `done + "개 중 " + total + "개 완료"`로
   조립해, 4개 중 1개를 완료하면 "1개 중 4개 완료"가 된다. 완료를 취소해 0개가 되면 "0개 중 4개 완료"다.

## 판단

- **1번은 `'`를 지웠다.** 약속명을 따옴표로 감싸는 안도 있었지만, 약속명 뒤의 "의"와 시간대가
  이어지는 문장이라 따옴표가 있으면 오히려 어색하고, 푸시 본문 한 줄에 글자만 늘어난다.
- **2번은 두 변수의 자리만 맞바꿨다.** 계산(`done`, `total`, `percent`)은 맞았고 출력 순서만 틀렸다.
  `fragment_home.xml`의 `tools:text` 디자인 타임 미리보기 문구도 같은 방향으로 틀려 있어 함께 고쳤다.

## 변경

- 백엔드 `NotificationStatusChangedListener.handle`: 본문의 `"' 복약을…"` → `" 복약을…"`.
- 프론트 `HomeFragment.updateProgress`: `total + "개 중 " + done + "개 완료"`.
- 프론트 `fragment_home.xml`: `tools:text="4개 중 3개 완료"`.
