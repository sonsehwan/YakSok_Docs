# 27. 친구 관련 다이얼로그에 "닫기" 버튼 반영

## 문제

.pen의 친구 관련 다이얼로그 4종(내 QR 코드, 친구 프로필, 친구 추가, 받은 친구 요청)에는 하단에
"닫기" 버튼이 있는데, 코드는 프로필 다이얼로그에만 오른쪽 위 X 아이콘이 있었고 나머지는 닫는 버튼이
없어 바깥을 눌러야만 닫혔다.

## 판단

- **.pen 방식 그대로 "닫기" 버튼을 하단에 둔다.** 프로필의 X 아이콘은 .pen에 없으므로 제거하고
  액션 버튼 아래 텍스트 "닫기"로 바꿨다. 친구 추가·받은 요청은 하단 중앙 텍스트 버튼
  (.pen `Button/Text`: g500, 14sp, 패딩 12/16), 내 QR 코드는 전체 폭 주황 아웃라인 버튼
  (.pen `Button/Outline`).
- **텍스트 버튼은 `Widget.App.DialogCloseButton` 스타일 하나로.** 레이아웃 3곳이 같은 모양을 쓰므로
  `values/styles.xml`에 두었다. 크기·위치(`layout_*`)는 스타일에서 지정되지 않아 레이아웃에 남는다.
- **프로필 id `btn_close`는 유지.** 타입만 `ImageView` → `TextView`로 바뀌고 `setOnClickListener`는
  그대로 동작해 프로필 쪽 Java 변경은 없다. 나머지 3개 다이얼로그는 `FriendListFragment`에서
  `btnClose`에 `dialog.dismiss()`를 연결했다.
- **SELF 프로필은 액션 버튼을 `GONE` 대신 `INVISIBLE`로.** .pen이 같은 높이를 유지하려고 Spacer를
  넣어둔 것과 같은 결과다.
- 다이얼로그 하단 여백은 .pen 값에 맞춰 16dp로 줄였다(닫기 버튼이 자체 세로 패딩 12dp를 가진다).

## 택하지 않은 대안

- **X 아이콘 유지 + 하단 닫기 추가:** 두 개의 닫기 수단이 생겨 .pen과 달라진다.
- **MaterialButton `TextButton` 스타일 사용:** 패딩·글자색을 매번 덮어써야 하고 최소 터치 영역(48dp)
  규칙 때문에 .pen의 12/16 패딩과 높이가 어긋난다.

## 알려진 차이

- 내 QR 코드 다이얼로그는 닫기 버튼만 반영했다. .pen은 안내 문구(10분 유효, "친구가 이 코드를 스캔하면
  내 프로필이 보여요")와 QR 크기(200)·닉네임 줄이 코드(5분 만료 문구, QR 220)와 다르다. 만료 시간은
  서버 값과 맞춰야 해서 확인 전에는 바꾸지 않았다.
